## Как работает проект:
1) запускается модуль toolkit, а там __main__.py запускается.
2) он вызывает тайпер
3) дальше выполняются в зависимости (токенизация,  валидация, и вычисление), или конвертер. 
4) и соответственно выводит ошибку или результат

# Основные команды:
Калькулятор: -> считает значение выражения через tokenization, validation, canculation.
1) Поддерживает целые и вещественные числа, также +,-,*,/, также унарные минусы и плюсы
2) Игнорирует пробелы
3) Соблюдает приоритет операций

1) python -m toolkit calc "EXPRESSION"
Пример:
<pre>
 Терминал:
 python -m toolkit calc "2*3 - 5/4"
 Вывод в терминал:
 4.75
</pre>
Конвертер: -> перевод из одной единицы в другую
Поддерживает:
длину mm,cm,m,km
массу g,kg
температуру c f k
<pre>
python -m toolkit convert VALUE --from UNIT --to UNIT
Пример:
</pre>
<pre>
 Терминал:
 python -m toolkit convert 2500 --from km --to m
 Вывод в терминал:
 2500000.0
</pre>
